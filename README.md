# NEXO FII

## Sobre o projeto

O NEXO FII é um simulador de investimentos em fundos imobiliários desenvolvido no Microsoft Excel durante o Santander Bootcamp Excel com Inteligência Artificial, promovido pela DIO.

A ferramenta permite realizar projeções com base no aporte mensal, no período de investimento e nas taxas estimadas de rendimento e dividendos. O projeto possui finalidade educacional e busca apresentar os resultados de maneira simples, visual e interativa.

## Funcionalidades

* Cálculo do aporte mensal sugerido;
* Simulação por valor, prazo e taxa de rendimento;
* Projeção do patrimônio acumulado;
* Estimativa de dividendos mensais;
* Comparação de cenários de 2, 5, 10, 15 e 20 anos;
* Definição de uma meta de renda mensal;
* Cálculo do patrimônio necessário para alcançar a meta;
* Indicador do percentual da meta já alcançado;
* Seleção do perfil do investidor;
* Distribuição do aporte entre diferentes tipos de FII.

## Como utilizar

1. Faça o download do arquivo `nexo-fii-simulador.xlsx`;
2. Abra a planilha no Microsoft Excel;
3. Preencha os campos destinados ao usuário;
4. Escolha o perfil na lista suspensa;
5. Altere os valores para comparar diferentes cenários;
6. Confira as projeções e a distribuição apresentada.

## Aprendizados

## Observação

Os resultados apresentados são estimativas educacionais e não representam garantia de retorno ou recomendação de investimento.
